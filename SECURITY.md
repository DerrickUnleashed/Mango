# Security Policy

Report security issues privately. Publicly opening an issue that describes a
real vulnerability is discouraged — it exposes the flaw before a fix ships.

## Supported versions

| Version | Status                |
| ------- | --------------------- |
| 0.1.x   | :white_check_mark: Supported |

The project is in active development; only the latest release receives
security fixes.

## Reporting a vulnerability

Send details to the repository owners by opening a private draft advisory
(Actions -> New draft security advisory) or by contacting the maintainers
directly.

Please include:

- the affected component (api / web / ml) and version
- a minimal reproduction, or a clear description of the trigger
- the impact you believe is possible

## Disclosure

We aim to confirm the report within 3 business days and coordinate a fix and
public disclosure together with the reporter. Do not publish the issue before
we agree on a release timeline.
