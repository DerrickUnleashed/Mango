| Component                    | Implemented Method                           | Key Technical Details                                                      |
| ---------------------------- | -------------------------------------------- | -------------------------------------------------------------------------- |
| Detection                    | YOLOv8 (YoloDetector)                        | Ultralytics YOLOv8; conf 0.35, IoU 0.45; sliced grid inference (N×N tiles, 20 % overlap); class `{0: "mango"}`; supports pretrained or fine-tuned `.pt` weights. |
| Tracking                     | ByteTrackAdapter (primary) / TAPNextTracker  | ByteTrack: two-stage IoU association (high-conf ≥ 0.5 first, then low-conf), KalmanBoxFilter, 30-frame buffer, match IoU 0.2. TAPNext++: point-track queries (centre), 120 px match threshold, 30-frame buffer, optional rebootstrap (default off). |
| Identity Learning            | Self-supervised InfoNCE + DBSCAN pseudo-labels | L2-normalised embeddings; DBSCAN on sub-tracklet centroids (eps 0.3, min_samples 3); 3-round curriculum (conf gate 0.85 → 0.5, decay 0.95); PairOptions: temporal window 15 frames, spatial gate 60 px, hard-negative top-8, batch 32, temp 0.1; TrackletPartitioner splits on frame gap >10, confidence drop, appearance drop <0.6 cos-sim. |
| Identity Memory              | Moving-average prototypes (quality-aware)     | Confidence-weighted EMA (rate 0.2 default); quality = conf × (0.55 if occluded); suppress below min_quality; prototype renormalised to unit norm; `is_confident` when obs ≥ 3 & quality ≥ 0.5. |
| Re-ID                        | Track-chain numbering + cosine similarity + motion gating | MockReIdentifier: identity = track chain number; reappearance matched by cosine sim ≥ threshold (config 0.6, default 0.8); motion gate: max displacement 120 px + 45 px/frame × gap; only unrecovered lost tracks are candidates; accepted match keeps original identity number. |
| Frame Processing             | Streaming single-frame decode                | `cv2.VideoCapture.read()` one frame at a time; detector → tracker → embedder each consume then release; peak memory O(1) per stage; max_frames cap (default 600) enforced per job. |
| Motion Compensation          | MeasuredMotionEstimator (median box-centre shift) | Observes consecutive frames, computes median centre displacement; compensates detections into stabilised coords for tracking, **decompensates back to raw coords before persistence**; StaticMotionEstimator for fixed cameras; MockMotionEstimator for drift tests. |
| Configuration & Auditability | Centralised `PipelineConfig` + pydantic `Settings` | Per-job `PipelineConfig` dataclass (inference_mode, conf, tracker, motion, reid_threshold, memory_rate, buffer_frames, sliced, model paths); persisted in `ProcessingJob` row; env-loaded `Settings` for deploy-time defaults (weights paths, DB, storage, Celery opt-in). |
| Testing                      | Pytest suite (unit + integration + scenario) | 17 test modules covering detection, tracking (ByteTrack/TAPNext), re-ID, memory, identity, clustering, pseudo-training, contrastive training, pipeline orchestration, evaluation metrics (IDF1, HOTA, ID-switches, fragmentation, count MAE/MAPE, recovery rate), camera motion; synthetic orchard scenario for deterministic CI. |
| Known Gaps                   | Celery path opt-in; TAPNext weights external; real embedding checkpoint path via env | Celery broker/result URLs unset → in-process background worker; `tapnext_checkpoint_path` must be downloaded separately; `EMBEDDING_MODEL_PATH` env var for self-supervised identity checkpoint; metrics fully implemented (no placeholders). |
